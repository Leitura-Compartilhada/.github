# Leitura Compartilhada

Leitor de EPUB para o navegador (PWA) que guarda a **posição exata** onde você parou, no nível do
parágrafo, e a sincroniza entre o celular e o computador.

- **Código aberto:** [`leitura-compartilhada`](https://github.com/Leitura-Compartilhada/leitura-compartilhada), sob a licença AGPL-3.0.
- **Estado:** em desenvolvimento, para uso pessoal.
- **Autor:** Getulio Vagner. Os commits e as tags deste repositório são assinados; confira o selo **Verified**.
- **Segurança:** relate vulnerabilidades de forma privada, pelo [`SECURITY.md`](https://github.com/Leitura-Compartilhada/leitura-compartilhada/blob/main/SECURITY.md) do repositório.

O desenvolvimento acontece em repositórios internos; o repositório público recebe uma cópia assinada a cada versão.
